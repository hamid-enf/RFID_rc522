# STM32H743 setup & wiring

The STM32H743 (Cortex-M7 @ up to 480 MHz) is the primary target of this
library. The platform adapter lives in `platform/stm32/` and is the **only**
place that includes the STM32 HAL.

## CubeMX / CubeIDE peripheral setup

| Peripheral | Configuration (CubeMX)                          |
|------------|--------------------------------------------------|
| SPI1       | Mode 0 (CPOL=Low, CPHA=1 Edge), MSB first, 8-bit, no hardware NSS (use a GPIO for CS) |
| GPIO CS    | Output push-pull, high speed, initial HIGH       |
| GPIO RST   | Output push-pull, initial HIGH                   |
| GPIO IRQ   | External interrupt, falling edge (optional)      |
| USART3     | 115200 8N1 (debug console)                       |

Clock: any; the adapter reads the CPU clock via `HAL_RCC_GetHCLKFreq()` for
the µs delay, so no hard-coded frequency is required.

## Wiring — SPI (recommended)

| MFRC522 | STM32H743       | Notes                          |
|---------|-----------------|--------------------------------|
| 3.3V    | 3.3V            |                                |
| GND     | GND             |                                |
| SCK  (D5) | SPI1_SCK    | PB3                            |
| MOSI (D6) | SPI1_MOSI   | PB5                            |
| MISO (D7) | SPI1_MISO   | PB4                            |
| SDA/NSS   | GPIO CS       | e.g. PA4 (any GPIO)            |
| RST (NRSTPD) | GPIO      | e.g. PA0 (optional)            |
| IRQ       | GPIO EXTI     | e.g. PA1 (optional)            |

Interface selection: the module must be strapped to SPI (pin **I2C = 0**, pin
**EA = 1**). Most breakout boards do this on-board.

## Wiring — I2C

| MFRC522 | STM32H743   | Notes                          |
|---------|-------------|--------------------------------|
| 3.3V    | 3.3V        |                                |
| GND     | GND         |                                |
| SDA     | I2C1_SDA    | PB7 (+ 4.7 kΩ pull-up to 3.3V) |
| SCL (D7)| I2C1_SCL    | PB6 (+ 4.7 kΩ pull-up to 3.3V) |
| RST (NRSTPD) | GPIO   | optional                       |
| IRQ     | GPIO EXTI   | optional                       |

Interface selection: pin **I2C = 1** (pull high). Default 7-bit address `0x28`
(EA low, all ADR pins low). See [i2c.md](i2c.md) for the full ADR table.

## Wiring — UART

| MFRC522 | STM32H743   | Notes                          |
|---------|-------------|--------------------------------|
| 3.3V    | 3.3V        |                                |
| GND     | GND         |                                |
| SDA (RX)| USART1_TX   | host TX → MFRC522 RX            |
| D7  (TX)| USART1_RX   | MFRC522 TX → host RX            |
| D5 (DTRQ) | GPIO      | optional flow control           |
| RST (NRSTPD) | GPIO   | optional                       |

Interface selection: pins **I2C = 0** and **EA = 0**. See [uart.md](uart.md)
for the baud-rate table and LSB-first framing caveats.

## Code — full STM32H743 example

```c
#include "mfrc522.h"

MFRC522_Handle_t rfid = {0};

int main(void)
{
    HAL_Init();
    SystemClock_Config();

    MX_GPIO_Init();
    MX_SPI1_Init();
    MX_USART3_UART_Init();

    /* Attach the SPI adapter. */
    if (MFRC522_STM32_SPI_Init(&rfid, &hspi1,
                               RFID_CS_GPIO_Port,  RFID_CS_Pin,
                               RFID_RST_GPIO_Port, RFID_RST_Pin,
                               RFID_IRQ_GPIO_Port, RFID_IRQ_Pin) != MFRC522_OK) {
        Error_Handler();
    }

    /* Initialize the reader (reset, version check, antenna on). */
    if (MFRC522_Init(&rfid) != MFRC522_OK) {
        Error_Handler();
    }

    while (1)
    {
        if (MFRC522_IsCardPresent(&rfid) == MFRC522_OK)
        {
            MFRC522_UID_t uid;
            if (MFRC522_ReadUID(&rfid, &uid) == MFRC522_OK)
            {
                /* UID in uid.bytes[], length in uid.length, SAK in uid.sak */
                MFRC522_HaltTag(&rfid);
            }
        }
    }
}
```

Switching to I2C or UART is a one-line change:

```c
MFRC522_STM32_I2C_Init(&rfid, &hi2c1, MFRC522_I2C_DEFAULT_ADDR,
                       RFID_RST_GPIO_Port, RFID_RST_Pin, NULL, 0);

MFRC522_STM32_UART_Init(&rfid, &huart1, MFRC522_UART_BAUD_115200,
                        RFID_RST_GPIO_Port, RFID_RST_Pin, NULL, 0);
```

The core library is unchanged in all three cases.

## Notes

- **CS handling**: the adapter drives CS manually (software chip-select); do
  not enable hardware NSS on the SPI peripheral.
- **Reset pin**: if no reset GPIO is wired, pass `NULL, 0` — the adapter
  falls back to a soft reset inside `MFRC522_Init()`.
- **IRQ pin**: pass `NULL, 0` to disable interrupts and poll instead.
- **RTOS**: the adapter's lock/unlock are NULL (single-threaded). For
  FreeRTOS, wrap the high-level calls in a mutex yourself, or extend the
  adapter's ops table with your own lock callbacks.
